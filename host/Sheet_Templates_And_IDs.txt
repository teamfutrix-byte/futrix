💡 QUICK GUIDE: HOW TO UPLOAD IN GOOGLE SHEET
--------------------------------------------------------------------------------
1. Is file ke tab-separated rows ko select karke copy (Ctrl+C) karein.
2. Apne Google Sheet me target cell select karein (e.g. A1 header ke liye, ya A2 next row ke liye).
3. Paste (Ctrl+V) kar dein. Google Sheet is tab-separated data ko pure table columns me distribute kar dega automatically.
4. Naya test series active karne ke liye:
   - Master Catalog sheet (jaise Topic-Wise Series) me details fill karein.
   - 'Questions' sheet me us test ke questions fill karein (aakhri column 'Series ID' me correct matching ID set karna na bhulein).
   - Top menu me **Futrix Portal > Sync Question Counts** run karein. Wo status ko check karke portal par test live kar dega!
